## 数据与编辑约定

新建日记先写入本机 SQLite。文件类记录保存时修改原 `.md` 文件，并留 `.bak`；数据库类记录只修改本地库，可通过「导出 .md」下载副本。导出文件与数据库副本内容相同时，列表只显示文件；两者不同则分别保留，防止隐藏用户的旧内容。相同正文的已保存日记和生成草稿合并展示。

修改前快照保存在 `journal_revisions` 表，数据库迁移版本为 7（新增独立 `reports` 表）。历史界面显示最近 50 个版本，载入只替换编辑器内容，点击保存才生效。手动编辑会标记需要重新核对，不授予事实确认状态，也不会把自由编辑文字自动提升为可信证据。

日记库不会重新采集来源，不调用模型。文件只在用户配置的日记目录范围内读取；拒绝目录穿越、Windows ADS、符号链接和特殊文件。第一版只支持 UTF-8，单文件 512 KiB，扫描文件总正文约 32 MiB、最多 2000 篇文件、8 层子目录；到达限制会提示。数据库日记和草稿分别最多加载 2000 条。

Markdown 是面向日记的基础子集，尚不是完整 CommonMark 编辑器。HTML 按文本显示，图片只显示说明，不自动加载远程内容；外链仅允许 HTTP、HTTPS、mailto。暂不支持正文全文搜索、图片管理、frontmatter 编辑、重命名或删除、自动保存及多机同步。

文件替换采用同目录临时文件并备份；文件与 SQLite 无法组成跨存储原子事务。异常时仍可能出现两个不同版本，列表会分别展示；多进程同时编辑的最终保障是版本检测和历史副本，不能声称实现了操作系统级文件锁。
