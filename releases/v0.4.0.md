## 日记库与桌面体验更新

- 设置窗口立即打开，来源探测在后台运行并缓存，避免每次打开都等待目录扫描。
- 模型连接测试显示等待秒数，并将探测时间限制在 15 秒内。
- 日记库支持独立选择多个文件夹，自动汇总子目录中的 Markdown 文件；与日记导出目录分开管理。
- 历史日记列表支持收起与展开，并记住上次状态。
- 桌面版新增更新提示：显示版本、发布日期和更新说明，由你决定是否下载；下载完成后可立即重启或下次启动更新。
- 更新前检查正在编辑的日记及保存任务，保留原有本地数据目录。

首次从 0.3 系列升级需安装一次此版本，之后可使用应用内更新。macOS 应用内安装更新需要使用 Developer ID 签名的版本。
